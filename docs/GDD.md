# 칸채움 v2 — 기획서 (업그레이드판 · 2026-10-11)

> 사용자 지시: «칸채움도 게임빌더 스킬 교훈대로 전면 업그레이드하고 배포» → 자동 승인(논스톱). 조사 = `RESEARCH.md`.

## 1-1 개요
- 이름 칸채움 · 장르 숫자 논리 퍼즐(스도쿠) · 웹(PWA)·안드로이드 래퍼 · 초등 3학년~성인.
- 한 줄: «작은 4×4 판에서 시작해 9×9 마스터까지 — 우리 학교 점수를 올리는 숫자 퍼즐».
- 교육 고리: 수학 «규칙 찾기·추론»(2022 개정 수학 변화와 관계) · 이용권 문제(키트 quiz).

## 1-2 코어 루프
판 시작(이용권 1장) → 칸 채우기(콤보·실수) → 판 끝 결과(점수·학교 +점) → 모드 최고기록 갱신 → 다음 판.
메타: 학교 순위(오늘/이번 주) · 오늘의 퍼즐 연속 · 레벨/코인/테마(기존 유지).
세션: 타임어택 90초~3분 · 서바이벌/대각선 3~10분 · 클래식 5~20분.

## 1-3 모드 (기본틀 ④ — 5종)
| kind | 이름 | 규칙 | 기록 |
|---|---|---|---|
| classic | 클래식 | 9×9 6단계(입문~마스터) 한 판 · 기존 콤보/힌트/파워업 | 난이도별 최고 점수 |
| time | 타임어택 | 90초 시작 · 4×4 3판 → 6×6 · 판 깨면 +12초 · 실수 −3초 · 0초면 끝 | 점수 |
| survival | 서바이벌 | 하트 3 · 실수 −1 · 판마다 커짐(4×4 2판 → 6×6 3판 → 9×9) · 힌트 없음 | 라운드 |
| rule | 대각선 | 두 대각선에도 같은 숫자 금지(X-스도쿠) · 4×4→6×6→9×9 · 하트 3 | 라운드 |
| daily | 오늘의 퍼즐 | 날짜 시드 9×9 한 판 · 연속 기록(기존) | 연속 일수 |
이용권 = 판(run) 1개에 1장 — 클래식 1판 · 오늘 1판 · 타임어택/서바이벌/대각선 한 판(라운드 여럿).
학교 점수 정산: 끝 = `gbFinish(ref, cleared)` (cleared = 클래식/오늘 완성, 런 모드 = 1판 이상 깸) · 중간 나감 = `gbLeave(ref)`.

## 1-4 수치
작은 판 엔진(`src/lib/mini/`): 크기 N∈{4,6,9}, 상자 2×2 / 2×3 / 3×3, 대각선 옵션. 모든 판 = 해 1개(유일해 검사).
| 모드 | 판 순서(크기·주어진 칸) | 점수 |
|---|---|---|
| time | 4×4(9,8,7) → 6×6(22,20,18,…최소 16) | 4×4 10점 · 6×6 30점 · 남은 콤보 ×1.0~1.5 |
| survival | 4×4(8,7) → 6×6(20,18,16) → 9×9(46,42,38,36,34,…최소 30) | 라운드 수 |
| rule | 4×4X(8,7) → 6×6X(20,18,16) → 9×9X(40,36,34,…최소 30) | 라운드 수 |
생성 시간 상한: 4×4·6×6 P95 < 50ms · 9×9(X 포함) P95 < 800ms(넘으면 주어진 칸 +2 로 물러남).

## 1-5 화면
- 홈(기본틀 셸): 머리줄(로고·전체화면·설정) → **학교 순위(맨 위·접지 않음)** → «시작하기»(classic 1개) → 모드 카드 2열(time·survival·rule·daily 같은 높이·설명 한 줄) → 보조 줄(도움말·인쇄·내 기록·상점).
- 런 화면(/time·/survival·/rule): 위 띠(시계/하트/라운드) · 판 · 숫자 패드(N개) · 지우기 · 나가기. 결과 시트(기록·최고·학교 +점·다시/홈).
- 클래식/오늘: 기존 화면 + 전체화면 단추 + 관문.
- 순위 화면(/leaderboard): 자유 입력 닉네임 랭킹 제거 → 학교 순위 + 내 모드별 최고.
