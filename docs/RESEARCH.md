# 칸채움 v2 업그레이드 — 조사 (2026-10-11)

기존 게임(9×9 스도쿠 6단계 · 오늘의 퍼즐 · 콤보 · 테마 상점)을 game-builder 기본틀(kit/school-hub)과 교훈 장부대로 끌어올린다.

## 비교 게임 (메카닉만 참고, 이름·UI 차용 없음)
| 게임 | 가져올 점 |
|---|---|
| Sudoku.com(Easybrain) | 난이도 6단계·실수 상한·일일 챌린지 — 이미 있음 |
| Good Sudoku(Zach Gage) | 막히면 «다음 기법» 힌트 — 기존 힌트 유지 |
| Sudoku Quest·Killer 류 | 변형 규칙(대각선·킬러)으로 같은 손맛에 새 제약 → **rule 모드 = 대각선** |
| 1010!/블록 퍼즐 타임어택 | 짧은 판을 연달아 깨며 시간을 버는 루프 → **time 모드 = 4×4·6×6 연속** |
| 2048·Tetris 마라톤 | 점점 커지는 판과 목숨 → **survival = 4×4→6×6→9×9** |
| 국내 «스도쿠 마스터»·«넘버 플레이스» | 초등 저학년이 9×9 에서 막힘 → **작은 판(4×4·6×6)으로 진입로** |
| 킹수학 등재 게임들(종이하늘 등) | 첫 화면 학교 순위·문제 풀고 이용권 = 기본틀 |

## 결론
- 초등생 진입로가 없다(9×9 입문도 첫 판에 61칸) → 4×4·6×6 작은 판 엔진을 새로 둔다.
- 자유 입력 닉네임 랭킹(욕설 필터)은 아동 개인정보 HARD 위반 → 제거하고 학교 순위로 대체.
- 저작권: 스도쿠 규칙은 공공재, 「칸채움」 이름 유지.
- 트랙: 일반(교실 1분 트랙 아님 — 9×9 한 판 5~20분). 단 time 모드는 90초 판.
